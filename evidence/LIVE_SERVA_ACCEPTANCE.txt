A DEFECT THIS ATTEMPT FOUND
------------------------------------------------------------------------

Before this run, `serva machine doctor` reported:

    Claude subscription..... READY
    Sandbox................. READY

on the same machine where the factory refused for exactly those two things. The
doctor had invented a weaker second opinion: it read the presence of a credentials
FILE as an authenticated SESSION, and it checked bubblewrap — which contains
Serva's own recipes — while a Producer is contained by a different mechanism
entirely.

A green diagnostic line sitting above a refusal is the "UI green does not mean
runtime green" failure this product exists to prevent, and it was in the newest
code in it.

Both are fixed. `CLAUDE_AUTH` now has no branch that returns READY from a file —
the best it reaches is UNKNOWN, naming `serva engineering doctor` as the authority
that asks the engine itself — and `SANDBOX_PRODUCER` is a separate check that says
plainly that bubblewrap is not a substitute for it. The doctor now names the same
two prerequisites the factory refused on.

That agreement is the point of one company underneath, and the live run is what
found it missing.
